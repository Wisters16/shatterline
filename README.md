# Shatterline

**Shatterline** is a fast-paced browser survival game set on a fragile sheet of ice.

Keep moving as the arena cracks beneath you, avoid pursuing enemies, use shockwaves to throw them into the water, collect power-ups, and survive long enough to unlock new cosmetics.

🎮 **Play Shatterline:**  
https://wisters16.github.io/shatterline/

## Gameplay

The arena becomes more dangerous the longer you survive.

Walking damages the ice, natural fractures appear across the map, enemies hunt you down, and broken tiles become permanent hazards for the rest of the run.

Your goal is simple:

**Survive for as long as possible.**

## Controls

| Action | Control |
| --- | --- |
| Move | WASD / Arrow Keys |
| Shockwave | Space |
| Pause / Resume | Esc |
| Retry | R |

## Features

- Dynamic destructible ice arena
- Irregular frozen coastline and floating ice
- Enemies that chase the player and can fall through broken ice
- Shockwave ability
- Natural fractures and progressive difficulty
- Repair, recharge, and shield power-ups
- Survival medals
- Best-time tracking
- Unlockable arena themes
- Unlockable player skins
- Unlockable movement trails
- Persistent progress using local storage
- Sound effects and Web Audio
- Snow, particles, screen shake, glowing ice and water effects
- Automatic pause when the browser loses focus

## Cosmetics

Surviving longer unlocks additional visual styles for:

- Arena
- Player
- Trail

Cosmetics are purely visual and do not affect gameplay.
